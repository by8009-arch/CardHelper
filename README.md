# 📇 CardHelper 名片管理助手

macOS 專屬智慧名片辨識、歸檔與聯絡人管理系統。

## ✨ 主要功能
- **Apple Vision 原生 OCR 與 QR Code 解碼**：支援中、英、日多語系名片自動轉正與欄位解析（姓名、英文名、公司、統一編號、部門職稱、電話、手機、傳真、Email、地址、網站、備註）。
- **單檔多張名片自動分割（最多 4 張）**：單張照片內含多張名片時，自動依空間座標分群並逐張建立名片資料。
- **智慧重複人員偵測與正反面合併**：同一公司、相同 Email、相同姓名或去除國碼後相同電話號碼，自動提示「更新（合併欄位）」或「覆蓋取代」，並將英文名置於中文名之後。
- **手動選取兩張名片合併**：可勾選任意兩筆名片資料進行互動式預覽與合併。
- **⭐ 標記「重要」自動同步 Mac 聯絡人 (`Contacts.app`)**：將名片標定為「重要」時，自動新增或更新至 macOS 電腦的「聯絡人」資訊。
- **自動命名歸檔與圖片壓縮**：提取完成或取消時，自動將名片圖檔依 `公司名稱.名字.副檔名` 移入 `done/` 目錄，並自動壓縮至 1MB 以下。

## 🚀 啟動方式
```bash
./start_cardhelper.sh
```
預設開啟於 `http://127.0.0.1:8765`。
